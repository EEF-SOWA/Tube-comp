# Fairchild 670 사진 레퍼런스

UI 질감 작업의 시각 참고 자료다. 제품 자산이 아니며, 빌드나 패키징에 포함되지
않는다. 페이스플레이트·로고·각인은 복제하지 않았고, 패널 텍스처는 코드로
생성한 EON 고유 자산이다(`Source/PluginEditor.cpp`의 그레인·램프·비네트).

## 참고한 것과 참고하지 않은 것

참고: 흑연색 패널의 반사와 마모, 노브 스커트·너클링 비율, VU 창의 가로 비율과
램프 배치, 좌상단 조명 방향.

참고하지 않음: Fairchild 상표·로고, 원본 각인 문구, 페이스플레이트 그래픽,
색상 배색 자체. EON 패널은 위 요소를 시대적 문법으로만 차용한 별도 디자인이다.
